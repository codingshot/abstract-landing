# Chain Abstraction Explorer

A comprehensive directory and resource hub for the Chain Abstraction ecosystem. This platform showcases projects, tools, and resources related to blockchain abstraction layers, account abstraction, and cross-chain infrastructure.

## 🌐 Overview

Originally created as a landing page for Abstraction Hacks (referenced in `pages/index.js`), this project is being transformed into a full ecosystem explorer for Chain Abstraction projects and resources.

## 📁 Project Structure

```bash
├── components/ # Reusable React components
│ └── items.js # Accordion component
├── pages/ # Next.js pages
│ ├── app.js # App entry point
│ ├── document.js # Custom document
│ ├── [redirect].js # Dynamic redirect handler
│ ├── 404.js # Custom 404 page
│ ├── index.js # Homepage
│ └── style.css # Global styles
├── public/ # Static assets
└── package.json # Project dependencies
```

## 🛠 Tech Stack

- [Next.js](https://nextjs.org/) - React framework for production
- [React](https://reactjs.org/) - UI library
- [Vercel](https://vercel.com/) - Deployment platform
- [CSS Modules](https://github.com/css-modules/css-modules) - Scoped styling

## 🚀 Getting Started

1. Clone the repository:
```bash
git clone https://github.com/codingshot/chain-abstraction-explorer.git
```

2. Install dependencies:
```bash
npm install
```

3. Run development server:
```bash
npm run dev
```
4. Build for production:
```bash
npm run build
```
